# Общий поиск Underwood — локальная проверка

Дата: 21 октября 2026 года. Адрес проверки: http://localhost:3005.

## Реализовано

- Поиск из общей шапки на всех frontend-страницах. Телефон и планшет используют полноэкранную панель; десктоп — окно шириной 720 px под настоящим полем. Первая строка шапки закреплена, вторая уходит с документом. После её ухода появляется лупа в заранее выделенном месте.
- Черновик панели отделён от применённого q каталога. Ввод, очистка черновика и отмена сохраняют фоновую страницу, карточки, фильтры, пагинацию, URL и прокрутку.
- Enter, лупа и CTA используют общую функцию применения. Из каталога сохраняются фильтры и perPage, сбрасывается page; с другой страницы передаётся только q. Пустая отправка снимает q. Применённый запрос виден и очищается отдельно от фильтров.
- Ленивая загрузка через `/api/plant-search`, задержка 150 ms, ограничение запроса 200 символами и preview четырьмя группами. Устаревшие ответы отменяются/игнорируются. Есть начальное состояние, загрузка, нулевой результат, ошибка и повтор.
- Источник — Payload через существующий адаптер. В ответе только публичная проекция. Настройки доступа CMS не расширены: `/api/product-variants` по-прежнему отвечает 403 без авторизации. Серверный read использует тот же доверенный путь, что полный каталог.
- Поиск использует общий matchesProductSearch. Предложения строятся из существующих variant.pots, ссылки — через productSelectionHref. Данные старого статического массива не используются.
- Основная строка показывает самое дешёвое доступное предложение; если в наличии нет ничего — самое дешёвое под заказ. Фото принадлежит выбранному предложению, иначе используется placeholder категории. Раскрытие сохраняет порядок групп, показывает реальные пары, цены и наличие; открыта одна группа.
- Dialog использует существующий Radix: блокировка фона/прокрутки, ограничение фокуса, доступные названия, Escape, возврат фокуса, aria-live. При раскрытии input теряет фокус для закрытия системной клавиатуры. Размер панели учитывает visualViewport.

## Проверки

Все перечисленные проверки прошли на итоговом коде:

- `pnpm exec tsc --noEmit`.
- Четыре целевых Vitest-файла, 16 тестов: product-search, product-selection, product-variant-sorting, global-search.
- 12 Playwright-сценариев из `tests/e2e/global-search.e2e.spec.ts`: основной прогон 11/11 и отдельный добавленный сценарий пагинации 1/1.
- `pnpm run generate:importmap`: новых импортов нет, файл не изменён.
- Проверка форматирования и `git diff --check`.
- `pnpm build`: успешно, включая TypeScript, генерацию 51/51 страниц и регистрацию динамического `/api/plant-search`.

Браузерные сценарии проверяют открытие с главной, каталога, статьи и растения; отмену и очистку черновика; три способа отправки; сохранение фильтров/perPage и сброс page; пустую отправку и IME Enter; точные ссылки размера, возраста и горшка, выбранные параметры, цену, наличие и загрузку фото после перехода/обновления; Back; медленный старый ответ; ошибку и повтор; отсутствие результата; Tab/Shift+Tab/Escape; закрытие подложкой; меню; resize; возврат фокуса и прокрутки; настоящую вторую страницу каталога при отмене; независимый сброс фильтров.

Синтетические данные Vitest дополнительно проверяют недоступный дешёвый вариант при наличии более дорогого, все варианты под заказ, отсутствие выдуманных пар, сортировку/детерминированность, счётчики до preview-ограничения, возраст/горшки и склонения.

## Границы проверки

- Настоящая системная клавиатура iOS/Android и поворот физического устройства не проверялись. Проверены настоящий input, blur при раскрытии, сохранение текста/фокуса при resize и работа с visualViewport; изображение клавиатуры не рисуется.
- 200% проверены как эквивалентная CSS-раскладка в Chromium, не как ручная смена browser zoom на устройстве.
- На главной при ширине 720 px отдельно обнаружен выход существующего блока фотографии за viewport на 6 px (x54 + ширина672 = 726). Он воспроизводится без открытого поиска; несвязанный блок главной не изменялся. Проверка overflow общего поиска и каталога проходит.
- Проверялся локальный Chromium. Safari/Firefox и production не проверялись. Figma, PRODUCT.md, схема БД и чужая правка статьи не изменялись. Деплой и push не выполнялись.
- Временный dev-сервер остановлен после браузерной проверки. Для просмотра локально: `pnpm dev`, затем http://localhost:3005. PNG доступны без сервера.
